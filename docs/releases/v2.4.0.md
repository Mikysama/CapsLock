# CapsLock v2.4.0

CapsLock 2.4.0 引入 inline/fullscreen 共用的类型化斜杠命令系统，并为 session 导航、维护模型调用和上下文边界增加可恢复审计。

## 命令系统

- P0：`/resume`、`/btw`、`/compact`、`/new`、`/copy`、`/export`。
- P1：`/branch`、`/context`、`/worktree`。
- P2：`/rewind`、`/stats`、`/doctor`。
- 命令拥有统一 usage、分组、运行约束和异步结果；session 导航关闭旧 Application 后重新组合目标 session，不原地替换 ID。

## Session 与上下文

- `/btw` 使用隔离 FAST 工具循环，复用普通 Agent Markdown 和工具结果展示；问答正文不进入 transcript、memory 或持久化事件，token/费用只进入 maintenance 用量。
- `/compact` 保存 active compaction 和可选聚焦说明；`/context` 使用稳定 snapshot 展示 token 分类与预算。
- `/branch` 和 `/rewind` 创建带 lineage 的派生 session，原 session 不截断；安全文件恢复通过 `session_rewind` Action 审计。

## 持久化与兼容性

- workspace schema 升至 9，新增 run kind、session lineage、active compaction state 和 context snapshots。
- backup、portable archive 和 session export 升至格式 4；archive 格式 3 仍可读取。
- config 5、memory schema 3、JSONL schema 3 和 plugin protocol 4 保持不变。
- workspace v6/v7/v8 使用 backup-first 事务迁移至 v9。

## TUI

- `/btw` 回答按普通 Agent Markdown 渲染，并在工具调用完成后原子展示，避免与主 run 输出交错。
- fullscreen 使用普通差分刷新，禁用兼容性不一致的 DEC 2026 synchronized-output。
