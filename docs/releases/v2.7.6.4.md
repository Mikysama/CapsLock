# CapsLock 2.7.6.4

本版修复模型响应终态、profile 切换、搜索、后台轮询与重试中的正确性问题，并改进长任务的诊断和恢复。

- 流式响应必须成功结束后才执行其工具；失败响应保留部分文本，且不自动重放已输出内容。`/model` 以配置中的 profile 切换完整 Provider、窗口与计价信息。
- 搜索统一依赖 ripgrep；进程输出支持按 offset 增量读取，Agent mailbox 增加进程内唤醒；无效 MCP 配置不再阻止应用启动。
- 上下文压缩优先依据输入预算、安全余量和最近轮次增长量，观测不足时使用 80% 兜底。内置工具输出契约与恢复调用校验得到统一。
- 新增可撤销的工作区编辑预设、`exec --output-schema`、本地 stdio app-server，以及 60 个离线内核回归场景。

workspace schema 升至 21、config 升至 14、portable archive 和 session export 升至 8；Memory schema 6 与 JSONL 3 不变。迁移会先备份。回退旧二进制前须恢复相应升级前备份。详情见 [开发与验证](../development/v2/v2.7.6.4.md) 与 [优化交付说明](../reliability-optimization.md)。离线回归不代表真实模型解决率或成本改善。
